## Phần 1: Đường Cơ Sở Cấu Hình (Configuration Baseline)

> Đường cơ sở cấu hình là tập hợp các hạng mục cấu hình (CI) được chính thức thống nhất và phê duyệt tại một thời điểm cụ thể.
> Theo AS9100D 8.1.3, phê duyệt CCB là bắt buộc khi thiết lập đường cơ sở.

| Số | Loại đường cơ sở | Số đường cơ sở | Tên đường cơ sở | Ngày thiết lập | Phạm vi CI áp dụng | Người phê duyệt CCB | Trạng thái | Ghi chú |
|------|-----------|---------|---------|------------|-----------------|---------|------|------|
| 1 | □ FBL (Chức năng) □ ABL (Phân bổ) □ PBL (Sản phẩm) | | | | | | □ Current □ Superseded | |
| 2 | □ FBL (Chức năng) □ ABL (Phân bổ) □ PBL (Sản phẩm) | | | | | | □ Current □ Superseded | |
| 3 | □ FBL (Chức năng) □ ABL (Phân bổ) □ PBL (Sản phẩm) | | | | | | □ Current □ Superseded | |
| 4 | □ FBL (Chức năng) □ ABL (Phân bổ) □ PBL (Sản phẩm) | | | | | | □ Current □ Superseded | |
| 5 | □ FBL (Chức năng) □ ABL (Phân bổ) □ PBL (Sản phẩm) | | | | | | □ Current □ Superseded | |

> **Giải thích loại đường cơ sở**
> - FBL (Functional Baseline): Đường cơ sở tại thời điểm xác định yêu cầu chức năng
> - ABL (Allocated Baseline): Đường cơ sở tại thời điểm phân bổ yêu cầu thiết kế cho từng CI
> - PBL (Product Baseline): Đường cơ sở tại thời điểm xác định yêu cầu chế tạo và thử nghiệm sản phẩm
